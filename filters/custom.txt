! Run ./update-rules.sh to apply changes.
!
! Syntax examples:
!   ||example.com^                 block every request to example.com and its subdomains
!   ||example.com^$third-party     block it only when embedded in other sites (third-party)
!   example.com##.banner           hide .banner elements on example.com
!   ##.sponsored-box               hide .sponsored-box elements on every site
!   @@||example.com^$document      never block anything on example.com (site exception)
!   @@||cdn.example.com/lib.js     do not block one specific file
!
